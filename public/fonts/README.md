# Geist fonts

The site uses the same Geist and Geist Mono variable fonts as before, served locally. Both cover Latin and weights 100–900; other scripts use the system fallback. CSS uses `font-display: swap`; only the primary text font is preloaded.

Sources downloaded on 2026-10-03:

- Geist Latin WOFF2: https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFWNOITd.woff2
- Geist Mono Latin WOFF2: https://fonts.gstatic.com/s/geistmono/v6/or3nQ6H-1_WfwkMZI_qYFrcdmhHkjko.woff2
- OFL licenses: https://github.com/google/fonts/tree/main/ofl/geist and https://github.com/google/fonts/tree/main/ofl/geistmono

License texts are included alongside the font files.
